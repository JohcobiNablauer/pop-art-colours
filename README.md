# Pop Art Colour Editor
This web application enables users to upload, modify, and preview images in a pop art style. The app offers tools to convert images to greyscale, recolour them, and map greyscale values to custom colours, making it a useful tool for art projects and education.

## Features
- Image Upload: Users can upload images in various formats (JPEG, PNG, etc.) to begin editing.

- Greyscale Conversion: Users can convert images to greyscale with adjustable levels, allowing for detailed control over the grey values.

- Colour Mapping: The app allows users to assign custom colours to different greyscale values, enabling the creation of pop art-inspired designs.

- Recolouring: After converting to greyscale, users can recolour the image by mapping new colours to each greyscale level, giving the image a unique pop art appearance.

- Preview Section: Users can compare the original, greyscaled, and recoloured versions of their image side by side for easy review and adjustment.

- Download: After transforming the image, users can use their browser’s built-in functionality to download the image in the desired format, allowing for easy selection of the file type.
